# travel-guide

不开深度推理时的行程攻略图。

用户要一份行程时，请求沿着一条写好的图往下走：听懂需求、先给一句快答、上网采集、写攻略、自检，通过后定稿。资料不够就再搜，写得不好就重写，网上没有来源就说明这次抓不到。模型只在节点里做事，下一步由这条图决定。

深度推理、子代理和沙箱不在这个仓库里。

## 文件

| 文件 | 用途 |
| --- | --- |
| `app/state.py` | 图上共享的状态 |
| `app/llm.py` | DeepSeek 调用 |
| `app/search.py` | 采集和补搜用的网页搜索 |
| `app/nodes.py` | 每个节点做什么 |
| `app/graph.py` | 节点和边 |
| `app/run.py` | 本地跑一次 |

密钥放在本机的 `DEEPSEEK_API_KEY`，或复制 `.env.example` 为 `.env` 后填写。`.env` 不会进仓库。
